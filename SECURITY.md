# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SigVault Desktop, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please email security reports to: **security@sigvault.org**

Include as much detail as possible:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial assessment**: Within 1 week
- **Fix or mitigation**: Dependent on severity

## Scope

This policy covers:

- The SigVault Desktop application (`sigvault-desktop`)
- Hardware wallet integration code
- Authentication and token handling
- Local data storage and encryption

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest  | ✅        |
| Older   | ❌        |

We recommend always using the latest release.
